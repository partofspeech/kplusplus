01

Параметры поиска

Пароль используется только для текущего запуска и не сохраняется приложением.

Укажите номер, дату и название закона для более точного поиска.

Документы и общая таблица сохраняются прямо в выбранную папку. При повторном запуске готовые документы пропускаются.

При неполном ответе текст берётся из браузера. Авторизация и выход выполняются через Chromium.

Если потребуется код входа или CAPTCHA, включите отладку и повторите запуск.
