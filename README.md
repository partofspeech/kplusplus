# Скачивание судебных решений

Приложение находит судебные решения по указанному федеральному закону и
сохраняет их на вашем компьютере. Для работы нужно заполнить форму в браузере.

Сейчас поддерживается **КонсультантПлюс, раздел «Высшие суды»**. Нужны ваш логин
и пароль. Скачиваются документы, доступные вашей учётной записи.
Поддержка других судов и сайта Судакт.ру ещё готовится.

## 1. Установите приложение

Установка нужна только перед первым использованием.

1. Скачайте папку приложения. Если получили архив, сначала распакуйте его.
2. Установите [Python](https://www.python.org/downloads/) версии **3.11 или новее**,
   если его ещё нет на компьютере. Это программа, необходимая для запуска приложения.
3. Откройте распакованную папку и запустите файл для своего компьютера:

| Ваш компьютер | Файл для установки |
|---|---|
| Windows | `install-windows.bat` |
| Mac | `install-macos.command` |

Дважды нажмите на нужный файл. Откроется окно с сообщениями об установке.
Дождитесь надписи **«Установка завершена»**. В первый раз установка может занять
несколько минут: приложение скачивает необходимые компоненты. Нужен интернет.

Если установка закончилась ошибкой, сохраните текст сообщения. После устранения
причины установку можно повторить — ваши настройки и скачанные документы сохранятся.

## 2. Откройте приложение

В той же папке дважды нажмите:

| Ваш компьютер | Файл для запуска |
|---|---|
| Windows | `start-windows.bat` |
| Mac | `start-macos.command` |

Откроются окно с сообщениями и страница приложения в браузере.
**Окно с сообщениями оставьте открытым**, пока пользуетесь приложением.

Если страница не появилась автоматически, откройте браузер и вставьте в адресную строку:

```text
http://127.0.0.1:8765
```

Страница работает на вашем компьютере. Для поиска документов нужен интернет.

## 3. Запустите скачивание

1. Введите логин и пароль от КонсультантПлюс.
2. В поле **«Федеральный закон для поиска»** укажите номер, дату и название закона.
3. Нажмите **«Выбрать папку…»** и выберите, куда сохранить документы.
4. Нажмите **«Начать выгрузку»**.
5. Дождитесь завершения. Справа будут показаны текущий этап и количество документов.

Пример поискового запроса:

> Федеральный закон от 25.07.2002 N 113-ФЗ «Об альтернативной гражданской службе»

Приложение не сохраняет пароль, введённый в форму. При следующем запуске
скачивания его нужно ввести снова.

## Что означают переключатели

| Переключатель | Когда использовать |
|---|---|
| **Режим отладки** | Показывает отдельное окно браузера, в котором приложение работает с КонсультантПлюс. Включите, если нужно ввести код подтверждения или пройти проверку при входе. |
| **Перезаписывать существующие файлы** | Заново сохраняет уже скачанные документы и обновляет их записи в таблице. Оставьте выключенным, чтобы продолжить прерванную выгрузку. |
| **Пробный HTTP-режим** | Дополнительный способ получения текста, который сейчас проверяется. Для обычного скачивания включать его необязательно. |

## Где найти результат

Нажмите **«Открыть папку»** в приложении.

В выбранной папке будут:

- **`судакты.csv`** — общая таблица результатов. Её можно открыть в Excel или другой программе для таблиц.
- **`consultantplus`** — папка с текстами решений в формате DOCX. Их можно открыть в Word или другой программе для документов.
- **`.kplusplus.sqlite3`** — служебный файл, который помогает продолжать скачивание после сбоя. Он может быть скрыт; удалять его не нужно.

Таблица содержит название и текст решения, ссылку, дату сохранения, примечание,
искомый закон и название источника. DOCX сохраняет текст решения; оформление
исходного документа может отличаться.

## Если скачивание прервалось

1. Снова откройте приложение.
2. Введите тот же закон и реквизиты входа.
3. Выберите **ту же папку с результатами**.
4. Оставьте **«Перезаписывать существующие файлы» выключенным**.
5. Нажмите **«Начать выгрузку»**.

Уже сохранённые документы будут пропущены, новые — добавлены в ту же таблицу.
Если документ отсутствует или его файл повреждён, приложение попробует сохранить его заново.

Если папка результатов создана старой версией приложения, выбирайте именно
папку, где лежат таблица и документы, даже если она называется датой.

## Как остановить работу

Чтобы прервать скачивание, нажмите **«Остановить и выйти из системы»** и дождитесь
завершения. Остановка может занять некоторое время.

После окончания проверьте сообщение о подтверждённом выходе из системы.
Если выход не подтверждён, проверьте сессию КонсультантПлюс вручную.

Чтобы закрыть само приложение, перейдите в окно с сообщениями и нажмите
**Ctrl+C**. На Mac тоже используется **Control+C**.
Закрытие одной вкладки браузера не останавливает скачивание.

## Если что-то не работает

| Что произошло | Что сделать |
|---|---|
| Приложение просит установить Python | Установите Python 3.11 или новее и повторите установку приложения. |
| После запуска не открылась страница | Проверьте, осталось ли открытым окно с сообщениями. Попробуйте адрес `http://127.0.0.1:8765`. |
| Нужен код подтверждения или проверка при входе | Повторите запуск с включённым «Режимом отладки» и завершите вход в появившемся окне браузера. |
| КонсультантПлюс сообщает, что учётная запись занята | Завершите предыдущую сессию через обычную кнопку выхода КонсультантПлюс. |
| Документ недоступен | Проверьте, открывается ли он при обычном входе с вашей учётной записью. |
| Не удаётся сохранить таблицу | Закройте её в Excel и повторите запуск в ту же папку. |
| Ошибка повторяется | Сохраните текст ошибки, сообщите, какой закон искали и на каком этапе возникла проблема. Пароль отправлять не нужно. |

## Для Linux

Откройте терминал в папке приложения и выполните:

```bash
./install.sh
```

После установки запустите:

```bash
.venv/bin/python -m interfaces.web.app
```

При установке Linux может запросить пароль пользователя компьютера.
Для окна выбора папки может потребоваться дополнительный компонент `python3-tk`.
